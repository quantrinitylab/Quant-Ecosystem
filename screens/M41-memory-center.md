# M41 — Memory Center UI

## Layout
Left: memory categories and source-app filters. Center: searchable memory cards grouped by type/project. Right: provenance/context panel.

Filters: All, Mail, Calendar, Drive, Contacts, Git, Cross-App; Preferences, Projects, People, Episodes, Knowledge, Inferences, Agent Actions.

Card: memory statement → type badge → source-app chips → confidence/freshness → last verified → used-by contexts → correct/forget/suppress/view source.

States: loading, empty, no-results, stale, contested, permission-reduced, deletion-pending, unavailable.

Design law: users should understand what Quanty remembers, why, source, freshness and impact within a few taps.
