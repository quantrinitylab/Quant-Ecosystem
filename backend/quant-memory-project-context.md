# M41 — Cross-App Project Context

Projects are a first-class context boundary for Quanty.

A project context can connect:
mail threads + meetings + people + files + repositories + issues + PRs + tasks.

Project membership and links are derived with provenance. A project context never grants access to any linked object. Retrieval still checks each source's current authorization.

Project context supports continuity: “continue the launch work”, “show what changed since yesterday”, and “prepare the client meeting” can assemble relevant evidence without database crawling.
