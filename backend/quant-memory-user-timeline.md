# M41 — Unified User Timeline

The timeline is a derived chronological view across Mail, Calendar, Drive, Contacts and Git.

Events are grouped into meaningful episodes rather than a raw event dump:
- communication episode
- meeting episode
- project episode
- document episode
- development episode
- agent-action episode

Timeline entries link to authoritative source objects and show source app, time, participants, project and confidence. It respects source permissions and excludes data the user cannot currently access.
