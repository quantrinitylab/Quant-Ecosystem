# @quant/cli

The official developer and power-user Terminal Command-Line Interface for the Quant Ecosystem.

## Capabilities

- `quant auth login`: Browser-based OAuth2 PKCE login + secure system keyring token persistence.
- `quant mail [inbox|read|send]`: Triage emails directly from the terminal.
- `quant drive [ls|upload|download|sync]`: File operations and background directory sync.
- `quant git [clone|pr|repo]`: CodeHub pull request creation, code review, and repository management (GitHub CLI equivalent).
- `quant calendar [agenda|book]`: Rapid calendar schedule inspection and booking generation.
