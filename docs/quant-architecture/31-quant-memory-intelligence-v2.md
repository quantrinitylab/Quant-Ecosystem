# Quant Memory Intelligence V2

## Pipeline

Source systems → event ingestion → extraction → entity resolution → candidate memories → consolidation → contradiction handling → canonical memory → graph + lexical + vector + temporal indexes → policy filtering → hybrid retrieval → context orchestration → Quanty/product experience.

## Design laws

1. Remember selectively, not indiscriminately.
2. Provenance is part of memory.
3. Inference is never silently promoted to fact.
4. Current source state beats stale memory.
5. Memory retrieval never grants authorization.
6. Derived indexes are rebuildable.
7. Forgetting propagates through every derivative.
8. Personalization is product-scoped even when memory is shared.
9. Sensitive signals require stronger boundaries.
10. Quanty receives minimum useful context, not the user's entire life.
