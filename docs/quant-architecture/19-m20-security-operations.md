# M20 — Security Operations & Abuse Response

## Definition of done
- Security incident lifecycle is defined.
- Detection/SIEM integration is defined.
- Account takeover response is scoped with Identity ownership preserved.
- Spam/phishing campaign response is defined.
- Forensic evidence handling and chain of custody are defined.
- Security automation has risk tiers and verification.
- Runbooks cover major incident classes.
- Privileged access review and break-glass controls are defined.
- Threat models map trust boundaries.
- Security exercises measure detection, containment, recovery, and blast radius.
- No incident is declared resolved without verified recovery.
