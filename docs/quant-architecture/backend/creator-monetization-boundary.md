# Creator Monetization Boundary

QuanTube, QuantGram, QuantWave, and other creator surfaces may generate creator earnings.

Economy provides:
- transaction/credit primitives
- payout references
- ledger primitives
- reconciliation
- fraud hooks

Creator domain owns:
- creator eligibility
- revenue-share policy
- content attribution
- earnings calculation inputs
- payout eligibility

Never treat a view/like/follower count as a financial transaction without an explicit monetization contract.
