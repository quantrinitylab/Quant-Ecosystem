# M22 — Internationalization & Localization

## Locale model
Store user/org locale preferences explicitly. Never infer locale from IP as authoritative user preference.

## Localize
- UI strings
- dates/times
- numbers
- pluralization
- relative time
- accessibility text
- system notifications
- product-generated content where applicable

## Engineering
Use stable message keys, versioned translation catalogs, fallback locale, and pseudo-localization tests.

User-generated email content is not automatically translated or rewritten.
