# M20 — Forensics & Evidence

## Evidence classes
Authentication events, authorization decisions, admin changes, delivery events, security decisions, workload/deployment events, and selected application telemetry.

## Evidence rules
- append-only where required
- integrity protected
- timestamped
- access controlled
- retention governed by M15
- access itself audited

Evidence minimization is mandatory: collect what is necessary to investigate and verify, not unlimited copies of private content.

## Chain of custody
Every analyst access, export, transformation, and disposition is recorded.
