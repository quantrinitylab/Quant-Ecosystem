# M24 — Organization Lifecycle

## Provisioning
Create organization → configure identity → verify domains → assign administrators → configure policies → provision users → validate product readiness.

## Suspension
Suspension restricts defined capabilities while preserving data and evidence according to policy.

## Closure
Closing an organization triggers product-specific lifecycle workflows. Data deletion follows M15 policies, retention, and legal holds.

Organization closure must not silently bypass external provider or backup retention requirements.
