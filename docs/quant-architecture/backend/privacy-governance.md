# M21 — Privacy Governance

## Required artifacts
- data inventory
- purpose registry
- retention mapping
- access matrix
- processor/provider inventory
- privacy impact assessments for high-risk features
- data-flow diagrams
- deletion/export verification evidence

## Change control
New AI, analytics, cross-domain, telemetry, or data-sharing capabilities require privacy review proportional to risk.

Privacy review does not replace security, legal, or product review.
