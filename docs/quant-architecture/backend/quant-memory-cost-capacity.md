# Quant Memory Cost & Capacity

Cost drivers: extraction models, embeddings, vector/graph storage, retrieval compute, event volume, consolidation, and retention.

Controls: bounded extraction, deduplication, tiered retention, batch consolidation, hot/warm/cold indexes, quotas, and backpressure.

Capacity dimensions include users, source events/day, memory candidates/day, active memories/user, graph edges, vectors, retrieval QPS, and feed personalization QPS.
