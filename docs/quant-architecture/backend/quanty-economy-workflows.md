# Quanty Economy Workflows

## Change plan
Understand → retrieve current plan → compare target → calculate effects → prepare action → approval if required → execute → verify.

## Spend credits
Understand operation → quote → check balance → prepare reservation → approval if required → execute operation → verify ledger result.

## Refund request
Retrieve invoice/payment → validate eligibility → prepare request → approval/policy → submit → verify provider/Economy state.

Each workflow is resumable and records partial/failure states.
