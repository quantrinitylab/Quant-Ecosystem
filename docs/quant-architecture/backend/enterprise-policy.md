# M24 — Enterprise Policy Engine

## Policy domains
- authentication
- session/device controls
- mail security
- retention/holds
- data residency
- external sharing
- Quanty/AI usage
- API/integration restrictions
- billing/quotas

## Evaluation
Policy is explicit, versioned, scoped, and auditable.

A policy restriction can deny an otherwise permitted operation; it cannot bypass platform security or legal constraints.
