# Quant Memory Multi-User & Sharing Boundary

## User memory

Personal memory belongs to the user and is not automatically visible to collaborators, organizations, or shared workspaces.

## Organization memory

Enterprise/workspace knowledge has separate ownership, retention, and authorization. It must not silently become personal memory.

## Shared objects

A shared file/event/project can create contextual relationships, but access to the shared object does not grant access to unrelated personal memories.

## Delegation

Agents acting for organizations receive organization-scoped memory only. Personal Quanty context remains separately governed.
