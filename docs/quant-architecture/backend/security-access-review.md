# M20 — Security Access Review

## Review scope
Privileged users, service identities, deployment identities, database access, object storage, security tooling, and emergency break-glass access.

## Controls
- least privilege
- periodic review
- just-in-time elevation where supported
- expiration
- separation of duties
- immutable/audited administrative actions

Break-glass access is exceptional, time-bounded, strongly audited, and reviewed after use.
