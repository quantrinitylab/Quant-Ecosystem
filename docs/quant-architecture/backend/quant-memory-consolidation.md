# Quant Memory Consolidation

CANDIDATES → CLUSTER → COMPARE EVIDENCE → DEDUPLICATE → UPDATE FRESHNESS → SUPERSEDE CONFLICTS → PROMOTE/EXPIRE.

Repeated consistent observations can strengthen confidence, but weak behavioral signals do not automatically become sensitive durable facts. Explicit correction outranks inference. Current authoritative state outranks stale memory.

Semantic compression may summarize multiple episodes but must retain provenance to underlying evidence.
