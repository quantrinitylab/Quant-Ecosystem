# M24 — Enterprise Quanty Governance

## Organization controls
Organizations may configure:
- whether Quanty is enabled
- allowed tool categories
- approval requirements
- memory policy constraints
- model/provider allowlists where supported
- data residency restrictions
- telemetry/privacy restrictions
- AI usage budgets

## Precedence
Platform safety → legal/privacy policy → organization policy → user preference.

User preference cannot override organization restrictions.
