# M20 — Security Runbooks

## Required runbooks
- suspected account takeover
- phishing campaign
- outbound spam burst
- malicious attachment campaign
- compromised admin
- leaked credential
- suspicious OAuth/session activity
- database compromise
- object-storage compromise
- provider compromise
- malware detection outage
- SIEM/event pipeline outage

Each runbook defines detection, containment, evidence preservation, communication, recovery, verification, and rollback/expiry.
