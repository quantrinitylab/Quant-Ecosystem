# Quant Memory Entity Resolution

Resolve people, projects, files, events, repositories, and topics against authoritative IDs where possible.

Hierarchy: explicit canonical ID → verified identifier → strong deterministic attributes → bounded probabilistic match → unresolved.

Probabilistic matching cannot silently merge high-impact entities. Corrections propagate to graph edges and memory references while preserving provenance. Identity resolution never exposes hidden contact data merely because records look similar.
