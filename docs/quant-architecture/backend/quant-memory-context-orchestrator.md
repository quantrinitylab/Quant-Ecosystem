# Quant Memory Context Orchestrator

INTENT → TASK TYPE → CONTEXT CONTRACT → AUTHORIZATION → LIVE SOURCE CHECK → MEMORY RETRIEVAL → GRAPH EXPANSION → TEMPORAL CHECK → CONTRADICTION CHECK → REDACTION → CONTEXT BUDGET → RESPONSE PACKAGE.

Current authoritative questions prefer live source queries. Context packages separate canonical facts, durable memories, historical episodes, graph relations, temporary signals, uncertainties, and provenance.

The orchestrator assembles context but never grants source permissions or mutates source state.
