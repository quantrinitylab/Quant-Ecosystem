# M25 — Subprocessor Governance

## Inventory
Maintain provider identity, service purpose, data classes, processing region, security posture, contract status, and review date.

## Change flow
Proposed → Security/Privacy review → Residency review → Legal review → Approved → Published → Monitored → Retired.

## Restrictions
A provider cannot receive a data class or region outside its approved scope.

## Incident
Provider security/privacy incidents enter M20/M21 response workflows.
