# M25 — Compliance Evidence

## Evidence classes
Policies, configuration snapshots, access reviews, deployment records, security tests, backup/restore results, incident reviews, training records, vendor assessments, and approved change records.

## Requirements
Evidence has owner, source, timestamp, scope, integrity metadata, retention class, and review state.

## Privacy
Evidence should contain references and bounded metadata rather than raw customer content whenever possible.

## Expiry
Time-sensitive evidence expires and requires revalidation.
