# Marketplace Domain

Marketplace owns:
- listings
- publisher profiles
- package/version metadata
- install records
- review state
- compatibility
- marketplace policy
- discovery metadata
- commercial offer references

It does not own:
- OAuth identity truth
- API authorization engine
- payment ledger
- product business data
- malware/security verdicts

Lifecycle:
DRAFT → SUBMITTED → REVIEWING → APPROVED → PUBLISHED → SUSPENDED → RETIRED.
