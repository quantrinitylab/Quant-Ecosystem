# M21 — Consent & User Choice

## Principles
Consent is not used as a blanket authorization mechanism.

Where consent/choice is legally or product-required, store:
- purpose
- scope
- version
- timestamp
- actor
- source
- current state

## Changes
Choice changes are versioned and propagated to dependent systems.

A withdrawal must define what changes immediately, what requires asynchronous processing, and what cannot be retroactively undone.
