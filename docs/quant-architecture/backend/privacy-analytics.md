# M21 — Privacy-Preserving Analytics

## Preferred methods
Aggregate events, coarse dimensions, sampling, thresholding, and short retention.

## Sensitive analytics
Relationship graphs, content-derived signals, behavioral patterns, and AI usage require explicit purpose and restricted access.

## Anti-leakage
Dashboards must avoid exposing tiny cohorts where individuals can be inferred.

Analytics systems are not authorization systems and cannot reconstruct deleted source content.
