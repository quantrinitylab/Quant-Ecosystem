# Quant Memory Contradiction Resolution

Conflict types: current-vs-stale, user-vs-inference, source-vs-derived, two authoritative sources, temporary-vs-durable.

Priority: current authoritative source → explicit user correction → explicit user statement → recent attributable evidence → historical evidence → model inference → weak signal.

States: UNCONTESTED → CONTESTED → RESOLVED or UNCERTAIN.

When uncertainty materially affects an answer, Quanty should disclose uncertainty or ask a focused clarification rather than guess.
