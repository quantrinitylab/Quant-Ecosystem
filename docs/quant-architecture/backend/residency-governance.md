# M22 — Residency Governance

## Required artifacts
- approved region catalog
- data-class residency matrix
- tenant residency policy
- cross-region transfer registry
- processor/provider region inventory
- failover eligibility matrix
- residency audit trail

## Change control
Adding a region, provider, index, AI model, or analytics system that receives tenant data requires residency review.

## Quanty
AI/model routing must respect the same residency policy. A cheaper or faster model in another region cannot override residency.
