# M25 — Compliance Framework Mapping

## Framework model
Represent external frameworks as requirement catalogs mapped to internal controls.

Potential mappings include SOC 2, ISO 27001, GDPR/privacy obligations, regional requirements, and customer contractual controls.

## Rule
A framework mapping is not a certification. Certification/attestation status is represented separately with issuer, scope, period, and evidence.

## Maintenance
Framework versions are versioned. Control mappings are reviewed when requirements change.
