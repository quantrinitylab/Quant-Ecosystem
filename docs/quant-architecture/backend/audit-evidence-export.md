# M25 — Compliance Evidence Export

## Export
Authorized enterprise customers may request bounded evidence packages according to entitlement.

## Security
Exports use scoped capabilities, encryption, expiration, access logging, and revocation where supported.

## Contents
Only the requested evidence scope is included. Raw customer message/file content is excluded unless explicitly required and authorized.

## Lifecycle
REQUESTED → PREPARING → READY → EXPIRED/REVOKED.
