# M20 — Spam, Phishing & Abuse Response

## Campaign detection
Correlate sender velocity, recipient diversity, complaints, bounces, URLs, attachment signals, account age, authentication posture, and cross-tenant indicators.

## Containment
- throttle sending
- quarantine suspicious messages
- block malicious indicators
- suspend abusive credentials
- isolate affected queues
- notify responders

Actions are scoped and reversible where possible.

## Anti-abuse principle
Do not use a single model score as truth. Security policy combines independent signals, confidence, history, and blast radius.
