# M24 — Delegated Administration

## Roles
Examples include Organization Owner, Organization Admin, Identity Admin, Mail Admin, Security Admin, Compliance Admin, Billing Admin, and Read-only Auditor.

## Scope
Every privileged action evaluates actor → organization → product → resource → operation.

## Separation
High-risk changes can require two-person approval or step-up authentication according to policy.

Delegated admin never receives unrestricted database access.
