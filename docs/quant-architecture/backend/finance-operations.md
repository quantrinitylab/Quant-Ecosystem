# Finance Operations Console

## Responsibilities
- payment investigation
- invoice review
- refund workflow
- credit adjustments
- dispute review
- reconciliation mismatches
- provider health
- promotion abuse review
- audit/evidence export

## Roles
Finance Viewer, Finance Operator, Refund Approver, Economy Admin, Auditor.

High-impact operations use dual control where configured: one operator prepares, another approves.

## Guardrails
Operators see masked payment references and minimum necessary personal data. Every mutation has actor, reason, scope, previous state, resulting state, and correlation ID.
