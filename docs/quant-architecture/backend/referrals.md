# Referrals

Referral lifecycle:
INVITED → CLICKED → SIGNED_UP → QUALIFIED → REWARDED → EXPIRED/REJECTED.

Qualification is server-side and versioned.

Rules:
- self-referral detection
- duplicate identity/device signals
- reward caps
- attribution window
- fraud review
- reversal on qualifying-event refund/chargeback where policy requires

Referral codes are opaque and non-sensitive.
