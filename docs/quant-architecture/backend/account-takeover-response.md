# M20 — Account Takeover Response

## Signals
Impossible or anomalous authentication patterns, credential changes, session anomalies, suspicious device changes, abnormal mail behavior, mass forwarding/filter changes, unusual exports, and security-tool alerts.

## Response levels
1. increase verification
2. revoke selected sessions
3. require step-up authentication
4. freeze high-risk actions
5. suspend account capabilities
6. escalate to security incident

## Safety
Containment must preserve evidence and avoid deleting legitimate user data. Account recovery is an Identity operation coordinated by Security Operations.

Quanty may explain signals or prepare actions but cannot independently declare account compromise or permanently lock a user.
