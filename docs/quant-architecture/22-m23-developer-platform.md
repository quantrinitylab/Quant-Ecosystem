# M23 — QuantMail Developer Platform & Public API

## Definition of done
- Public API ownership is explicit.
- OAuth/app authorization is defined.
- Least-privilege scopes are stable.
- API versioning/deprecation is defined.
- Cursor pagination and stable errors are defined.
- Webhooks are signed, deduplicated, retryable, and replayable.
- Rate limits protect shared capacity.
- Sandbox is isolated from production.
- SDK contracts are testable.
- Developer observability respects privacy.
- Third-party integrations have governance and revocation.
- Public API security is tested against tenant and scope boundaries.
