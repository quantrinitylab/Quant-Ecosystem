# M37 — Quanty in QuantMail UX

## Read assistance
Summarize thread, extract action items, identify questions, extract deadlines, explain security signal, find related person/event/file.

## Draft assistance
Draft reply, rewrite tone, shorten/expand, suggest subject, clarify, translate where supported.

## Planning assistance
Prepare reply, prepare follow-up, prepare calendar action, prepare file organization. Preparations show proposed mutations before approval.

## Placement
Thread-level assistance appears near the relevant object. Global Quanty remains available from the workspace shell. Avoid persistent giant chat panels that consume the reading surface.

## Trust
Every generated claim is distinguishable from canonical source data. Quanty cannot invent sender identity, delivery state, event state, file state, or security verdict.
