# M39 — Quanty in QuantDrive UX

## Read assistance
Summarize a document where authorized, explain file metadata, find related files, locate duplicates, identify recent relevant files, summarize activity, explain sharing/security state.

## Organization assistance
Suggest folder placement, naming, tags, grouping, duplicate review, and archive candidates. Suggestions never silently move or delete files.

## Action preparation
Prepare rename, move/copy, share change, restore version, restore trash, or organize operation. Mutating actions require the normal Drive authorization and approval policy.

## Cross-product assistance
Find related Mail, Calendar, Contacts, or Git context without copying those products' authoritative records into Drive.

## Placement
Use contextual action cards near the selected file and a global launcher. Avoid a permanent chat panel consuming file space.
