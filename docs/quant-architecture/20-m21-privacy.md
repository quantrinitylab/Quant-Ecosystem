# M21 — QuantMail Privacy Architecture

## Definition of done
- Privacy ownership is distinct from product data ownership.
- Data minimization is enforceable through schemas and access boundaries.
- Quanty has explicit privacy/context boundaries.
- Telemetry excludes private content by default.
- Encryption and key scopes are separated by sensitivity.
- Consent/choice is versioned where applicable.
- Cross-domain data access is purpose-bound.
- Privacy requests orchestrate owning domains.
- Privacy incidents have dedicated response paths.
- Governance artifacts and privacy-impact review are defined.
- Privacy controls are tested against real authorization boundaries.
