# M38 — QuantCalendar UI/UX Journey Map

## Daily planning
Today → Week → inspect events → resolve conflict → return to plan.

## Meeting creation
Quick create → full editor → participants → availability → candidate time → explicit confirmation → verified event.

## Invitation
Mail invitation → Calendar event → RSVP → authoritative response → return to Mail.

## Rescheduling
Event → Quanty proposal or manual edit → conflict/participant impact → approval → save → verify.

## Deep work
Week → selected event → related Drive/Contacts/Mail → return with original Calendar context intact.

## Timezone workflow
Event → timezone details → compare local/participant time → save only if explicitly changed.

## Completion criterion
Design and frontend teams can implement Calendar primary workflows without inventing navigation, ownership, time semantics, or async-state behavior.
