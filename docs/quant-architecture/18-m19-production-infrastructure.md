# M19 — Production Deployment & Infrastructure Architecture

## Definition of done
- Environment boundaries are explicit.
- Kubernetes workload classes and failure-domain rules are defined.
- PostgreSQL HA and recovery are defined.
- Redis/Kafka failure behavior is defined.
- Secrets and workload identity are separated.
- Terraform, Helm, and GitOps responsibilities are clear.
- Canary, rollout, rollback, and migration safety are defined.
- Network segmentation and egress controls are defined.
- Release observability is mandatory.
- DR boundaries and tests are explicit.
- Production claims require exercised evidence.
