# M39 — QuantDrive Mobile UX Contract

## Home
Compact entry points for Recent, Shared, Starred, and My Drive. Upload/New is a prominent but non-blocking action.

## Folder
Rows prioritize icon/type, name, modified time, and sharing state. Long press opens selection/action mode.

## Preview
Full-screen viewer with safe controls. Details, sharing, versions, and related actions open as sheets.

## Upload
System picker integration with an upload queue. Progress survives navigation. Failures remain recoverable and explain destination/state.

## Gestures
Swipe can expose low-risk actions such as star; destructive operations require undo/confirmation. Pinch/zoom is available for supported image/document viewers.

## Navigation
Back restores folder/search context. App switching preserves Drive navigation and upload state where possible.
