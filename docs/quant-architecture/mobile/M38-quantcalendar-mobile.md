# M38 — QuantCalendar Mobile UX Contract

## Primary mobile surface
Today/Agenda is the default execution surface. Day view is the fastest detailed schedule view.

## Week/month
Week supports horizontal date navigation and vertical time navigation. Month prioritizes orientation and opens selected date into agenda details.

## Event
Event detail is a focused page. Primary actions are RSVP/edit when authorized; secondary actions include share/copy details, related objects, and reminders.

## Create
Quick create opens a compact sheet for title/time. Full editor expands to guests, location, recurrence, reminders, calendar, timezone, and related context.

## Gestures
Tap opens event; long press may initiate quick create or drag only where discoverable. Swipe date navigation must not interfere with vertical schedule scrolling.

## Navigation
Back restores the previous view/date/scroll position. App switching preserves Calendar context.
