# M37 — QuantMail Mobile UX Contract

## Inbox
Compact top app switcher/search/action row. Mode selector is horizontally scrollable when needed. Thread rows use 2–3 information tiers: participant + subject, snippet, metadata.

## Thread
Full-screen reading surface. Sticky action affordance may expose reply/archive/snooze/more. Attachments and related context open as sheets.

## Compose
Full-screen focused composer. Keyboard-safe recipient and send controls. Autosave status is visible but unobtrusive.

## Gestures
Swipe archive/snooze can be enabled with undo. Long press exposes selection/actions. No destructive action is gesture-only.

## Navigation
Returning from a thread restores inbox scroll/filter position. App switching preserves Mail navigation state.
