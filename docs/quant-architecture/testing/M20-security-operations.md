# M20 — Security Operations Testing

## Exercises
- account takeover simulation
- phishing campaign
- spam burst
- malicious attachment
- credential leak
- compromised admin
- suspicious session
- SIEM outage
- detection false-positive surge
- automation failure
- evidence-access audit
- break-glass access
- regional/infrastructure compromise

## Evidence
Measure detection time, triage time, containment time, recovery time, false positives, blast radius, evidence integrity, and customer impact.

No security automation is considered production-ready until failure and rollback behavior are exercised.
