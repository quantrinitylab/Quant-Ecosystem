# M21 — Privacy Testing

## Required tests
- cross-tenant access attempts
- unauthorized Quanty context access
- prompt/tool scope escalation
- telemetry redaction
- deletion propagation
- export completeness
- consent/choice propagation
- embedding/derived-data deletion
- cache invalidation after privacy change
- backup/restore privacy behavior
- analyst access auditing
- small-cohort analytics leakage

## Evidence
Record test scope, expected policy, observed behavior, data classes affected, and verification result.

Privacy readiness requires tested enforcement, not documentation alone.
