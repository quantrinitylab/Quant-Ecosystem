# M22 — Globalization & Multi-Region Testing

## Required tests
- locale fallback
- pseudo-localization
- DST gaps/folds
- timezone changes
- regional routing
- residency enforcement
- blocked cross-region transfer
- regional outage
- provider outage
- search locality
- attachment locality
- failover and failback
- cross-region queue reconciliation
- capacity during failover

## Evidence
Capture user-visible impact, data movement, recovery time, data consistency, residency decision, and capacity headroom.

No multi-region readiness claim is accepted from DNS configuration alone.
