# M32 — Quant Data Platform & Intelligence

## Goal
Define the shared analytical data platform without weakening product ownership, privacy, or source-of-truth boundaries.

## Surfaces
- Data platform overview
- Product analytics
- Operational dashboards
- Data quality
- Event catalog
- Data lineage
- Privacy controls
- ML feature datasets
- Warehouse/lake operations
- Data export

## Principle
Operational databases remain authoritative. Analytical systems are derived, governed copies.
