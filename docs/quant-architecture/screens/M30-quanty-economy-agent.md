# M30 — Quanty Economy Agent

## Goal
Define how Quanty can understand, explain, and safely orchestrate Economy without becoming an unrestricted financial actor.

## Modes
- Explain: plans, credits, invoices, usage
- Analyze: spending/usage patterns
- Prepare: checkout, plan change, refund request, credit spend
- Execute: only policy-permitted actions with required approval
- Verify: reconcile external outcome with Economy truth

## Hard boundary
Quanty never becomes the source of truth for balances, prices, subscriptions, invoices, or financial state.
