# M38 — QuantCalendar Visual Language

## Hierarchy
Current time and selected date are strong anchors. Event title/time dominate. Supporting metadata is compact.

## Density
Week/day use high information density; month uses compact summaries; agenda uses readable rows. Density never collapses touch/accessibility targets.

## Conflict
Conflicts use semantic indicators, geometry, labels, and supporting text rather than color alone.

## Focus
The active event, current time, selected day, and pending scheduling operation must be visually distinct without excessive animation.

## Empty states
An empty day should communicate that the calendar is clear and provide useful actions such as create event or find availability.
