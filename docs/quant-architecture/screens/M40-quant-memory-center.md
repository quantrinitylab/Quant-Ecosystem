# M40 — Quant Memory Center UX

## Purpose

Give users a real product surface for understanding and controlling what Quant remembers.

## Navigation

Memory Center lives inside QuantDrive but is distinct from ordinary files.

Sections:
- Overview
- Remembered about me
- Preferences
- Projects & goals
- People & relationships
- Important moments
- Saved knowledge
- Recent context
- Inferences/signals
- Memory activity
- Privacy controls

## Overview

Shows useful memory categories, recent memory changes, and personalization status. Avoid surveillance-style dashboards.

## Memory detail

Statement → type → source → freshness → confidence/uncertainty → used by → controls.

## Controls

Correct, forget, suppress, expiry, inspect source, report incorrect, personalization toggle where applicable.

## Inferences

Clearly separated from confirmed memory. Temporary signals should show expiry/ephemeral behavior where useful.

## Quanty explanation

“Why did you remember this?” explains provenance at a user-comprehensible level. Never expose hidden chain-of-thought.
