# M33 — Experimentation & Product Intelligence

## Goal
Define a safe experimentation platform for product, UX, AI, ranking, and economic hypotheses.

## Surfaces
- Experiment catalog
- Assignment/debug view
- Exposure dashboard
- Metric analysis
- Guardrail alerts
- Rollout controls
- Experiment audit
- Decision archive

## Laws
- Experiments never bypass authorization or security policy.
- Economic experiments use typed economic policies.
- Randomization and exposure are reproducible.
- Primary metrics are declared before analysis.
- Safety/reliability guardrails can stop an experiment.
- Historical results remain immutable evidence.
