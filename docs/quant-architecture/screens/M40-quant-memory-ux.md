# Quant Memory UX — Deep Product Surface

## Memory Center

QuantDrive should eventually expose a dedicated Memory Center alongside files, not hide memory inside a settings page.

## Sections

- Remembered about me
- Preferences
- Projects & goals
- People & relationships
- Important moments
- Recent context
- Saved knowledge
- Inferences/signals (clearly separated)
- Memory activity
- Privacy & controls

## Memory card

Show concise statement, type, source/product, freshness, confidence indicator where appropriate, and controls: correct, forget, inspect source, expiry.

## Source boundary

A memory card must clearly indicate “derived from” rather than pretending the memory itself is the original source.

## Quanty recall

When Quanty uses a memory materially, it can offer a lightweight “Why I know this” affordance linking to permitted provenance.

## Feed personalization UI

Users should understand that recommendations can use their activity/preferences. Sensitive inferred labels should not be surfaced as factual personality or mood claims.

## Mobile

Memory Center uses grouped lists and focused detail sheets. High-sensitivity memory controls require deliberate confirmation.
