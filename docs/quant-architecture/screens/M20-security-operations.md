# M20 — QuantMail Security Operations

## Goal
Define the operational security layer for detecting, containing, investigating, and recovering from attacks against QuantMail.

## Security lifecycle
Observe → Detect → Triage → Contain → Investigate → Eradicate → Recover → Review.

## Major threat classes
- account takeover
- credential/session abuse
- phishing campaigns
- spam/bulk abuse
- malicious attachments/URLs
- API abuse and automation
- insider/admin misuse
- provider compromise
- infrastructure compromise
- data exfiltration

## Operating principles
Security automation may reduce blast radius, but high-impact actions remain policy-controlled and auditable.

Normal product availability must be preserved where safe; security incidents must not silently become data-integrity incidents.
