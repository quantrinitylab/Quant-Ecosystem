# M39 — QuantDrive Visual Language

## Hierarchy
File/folder name is primary. Type, modified time, owner, and sharing state are secondary. Size and detailed metadata recede until useful.

## Grid/list
List is the power-user default on desktop; grid is the visual browsing mode. Both expose the same core actions and state.

## Preview
The viewer should feel like a focused workspace, not a modal trapped inside a tiny card. Navigation and metadata remain available without obscuring content.

## Status
Scanning, blocked, unavailable, pending upload, and shared states use semantic iconography/text plus restrained visual emphasis.

## Empty states
Explain the empty state and provide a useful next action: upload, create folder, open shared content, or clear filters.
