# M36 — QuantContacts UI/UX

## Information architecture

Contacts is the canonical people workspace. It must distinguish saved contact facts from interaction-derived context.

Primary views: People, Favorites, Groups, Organizations.

## Person profile

Profile sections: identity, verified contact methods, organization/role when known, notes owned by Contacts, groups, and related interactions. Mail/calendar/Drive/Git context is presented as linked context, not copied source data.

## Unknown person

An unknown sender remains an unknown sender. The interface may offer Add to Contacts but must not fabricate a name or organization.

## Relationship context

Interaction frequency, latest interaction, shared events/projects, and Quanty summaries are clearly marked as derived context. Sensitive relationship inference is not presented as canonical fact.

## Mobile

Person profile uses a focused page with primary contact actions above secondary relationship/context information.
