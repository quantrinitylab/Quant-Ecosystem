# M37 — QuantMail Visual Language

## Hierarchy
Unread mail is prominent through typography/weight and semantic emphasis, not oversized cards. Read mail remains easy to scan. Important/security states use consistent semantic treatment.

## Density
Compact mode is the default desktop target. Comfortable mode increases breathing room. Touch mode increases hit areas. Density must not alter semantic order.

## Context
Related people/events/files appear as lightweight context, not competing content columns. Quanty suggestions use a recognizable but restrained visual treatment.

## Empty states
Empty states explain why the state is empty and provide the next useful action. Do not use decorative illustrations when they delay comprehension.

## Error states
Errors are actionable, specific, and honest about whether the server has confirmed the requested mutation.
