# M35 Security — Communications

- Provider credentials use workload identity/secrets controls.
- Message payloads are minimized and classified.
- Unsubscribe/suppression is enforced server-side.
- Provider callbacks require authentication/replay protection.
- Sensitive links use scoped, expiring capabilities.
- Template variables cannot inject privileged actions.
- Delivery logs exclude unnecessary private content.
- Security and transactional messages have explicit priority policies.
