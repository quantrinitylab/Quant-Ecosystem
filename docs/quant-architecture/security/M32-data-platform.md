# M32 Security — Data Platform

- Data classification is enforced at ingestion and access.
- Raw private content is minimized.
- Analytical credentials use workload identity.
- Dataset access is audited.
- Sensitive joins require purpose and policy.
- Feature datasets cannot bypass product authorization.
- Deletion, legal hold, and residency controls propagate to derived data.
- Data exports are scoped, encrypted, and audited.
