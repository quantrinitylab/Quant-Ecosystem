# M29 Security — Marketplace

- Signed artifacts and provenance are mandatory.
- Requested permissions are visible before authorization.
- Runtime authorization is independent of marketplace approval.
- Publisher identity and package ownership are protected.
- Sensitive scopes require stronger review.
- Malicious/revoked packages can be suspended.
- Publisher telemetry excludes private user content.
- Payout operations use least privilege and reconciliation.
- Emergency moderation is auditable and appealable.
