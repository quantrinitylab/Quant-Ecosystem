# M28 Security — Economy Integration

- Product services receive least-privilege Economy scopes.
- Economy endpoints enforce product identity and account/org scope.
- Credit quotes and reservations are short-lived.
- Usage events are authenticated and replay-safe.
- Economic policy changes require approval/audit.
- Creator/ad monetization cannot bypass Economy financial controls.
- Sandbox credentials cannot access production financial state.
- Cross-product analytics use minimum necessary data.
