# M30 Security — Quanty Economy

- Model output never directly authorizes financial mutation.
- Financial tool calls require policy evaluation.
- Approval envelopes are exact, scoped, and expiring.
- Untrusted email/invoice text cannot override tool policy.
- Sensitive financial context is minimized.
- Quanty cannot invent balances, invoices, prices, or payment outcomes.
- Post-action verification is mandatory for side effects.
- High-impact failures are audited and evaluated as safety regressions.
