# M37 — QuantMail UI/UX Map

## User journeys

### Morning triage
Inbox → Focus → thread → action/reply → archive/snooze → next thread.

### Deep work
Needs You → thread → Quanty summary/action extraction → draft reply → review → send.

### Retrieval
Universal search → Mail filter → result → thread → related Calendar/Drive/Contact → return.

### Attachment workflow
Thread → attachment → security/scan state → preview → save/open in Drive → return.

### Meeting workflow
Invitation thread → related event → Calendar-owned RSVP/edit → return to thread.

### Sender workflow
Unknown sender → Contact context → Add to Contacts → canonical Contacts profile → return.

### Safety workflow
Suspicious thread → warning → security details/quarantine → authorized release or leave blocked.

## Completion criterion
A designer or frontend engineer should be able to implement the primary QuantMail workflows from this map without inventing navigation, ownership, or state behavior.
