# QuantMail — Flagship Product Architecture

QuantMail is the reference product for proving the per-product architecture.

Role: identity root, productivity hub, mail domain owner and host for Drive/Docs/Calendar/QuantGit surfaces.

Competitive thesis: do not clone Gmail; beat it on information density, search, keyboard speed, contextual work, cross-domain intelligence, automation and mobile ergonomics.

Primary journeys:
1. receive → triage → open → reply
2. search → find → act
3. compose → attach → send → verify
4. email → person → meeting → file
5. email → project → Git activity
6. Quanty → plan → approval → action
7. mobile inbox → thread → reply
8. admin → policy → audit

Implementation order: M01 Inbox, M02 Thread, M03 Compose, M04 Search, M05-M12 cross-domain productivity, M13-M20 Quanty/security/admin.
