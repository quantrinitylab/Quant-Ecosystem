# M09 — Quanty Attention Integration

Quanty can help explain and prioritize attention but cannot invent source state.

## Allowed

- summarize why an item needs attention
- group related items
- identify likely deadline
- explain source signal
- propose next action

## Restricted

Quanty cannot:
- silently change source priority
- dismiss security events
- resolve work without the source command
- fabricate an urgent state
- bypass notification policy

## Quanty task completion

When a verified Quanty task completes, Attention may create a completion item according to user preferences.

Approval-required tasks create attention items with explicit approval state.
