# M14 — Quanty Trust Integration

Quanty can:
- explain a security warning
- summarize evidence categories
- compare signals
- explain why a message was quarantined
- guide a safe recovery workflow
- summarize abuse trends for authorized admins

Quanty cannot:
- declare a message safe without current policy evaluation
- release quarantine without authorization
- override malware/attachment controls
- change reputation directly
- suppress security alerts
- reveal protected detection rules

Quanty is an explanation/orchestration layer over security truth.
