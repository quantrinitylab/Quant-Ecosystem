# M16 — Incident Response

## Lifecycle

DETECTED -> TRIAGED -> MITIGATING -> RECOVERING -> RESOLVED -> REVIEWED

## Severity

Severity is based on:
- user impact
- security impact
- data integrity
- duration
- scope

## During incident

- assign incident commander
- freeze risky changes where necessary
- establish timeline
- communicate verified facts
- track mitigation
- preserve evidence

## Review

Post-incident review records:
- impact
- root/contributing factors
- detection
- mitigation
- recovery
- follow-up actions

No blame-oriented postmortem language.
