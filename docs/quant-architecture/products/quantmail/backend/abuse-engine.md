# M14 — Abuse Intelligence

## Signals

- sending velocity
- bounce rate
- complaint rate
- unusual recipient patterns
- account/device anomalies
- authentication changes
- repeated policy violations
- coordinated abuse indicators

## Actions

- warn
- rate limit
- require step-up authentication
- restrict sending
- quarantine
- temporary block
- escalate to security review

## Fairness

Actions use bounded evidence and reviewable policy.
A single weak signal must not permanently suppress a legitimate account.

## Recovery

Restricted accounts have explicit recovery/review paths.
