# QuantMail Web — M11 Admin

## Layout

Admin uses a dedicated product-admin shell:
- admin navigation
- scope/org selector
- page header
- status/metrics
- data table
- detail drawer
- action confirmation

## Bulk operations

Before broad mutation:
- show scope
- affected count
- expected effect
- irreversible warning where applicable

No destructive action is hidden behind generic row hover controls.

## Audit

Every sensitive action links to its audit record.
