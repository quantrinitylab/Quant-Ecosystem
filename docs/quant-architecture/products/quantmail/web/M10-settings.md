# QuantMail Web — M10 Settings

## Desktop

Three-column structure:
- settings navigation
- active section
- contextual help/detail

Use dense information hierarchy without turning every option into a card.

## Save behavior

Prefer immediate validated saves for simple preferences.
Use explicit Save for compound forms.
Show saved/saving/error state.

## Security-sensitive

Password/passkey/MFA/session changes require step-up flow and clear confirmation.

## Deep links

Settings links can open a precise section without exposing internal domain IDs.
