# M15 — Quanty Data Lifecycle

Quanty may:
- explain retention
- summarize export scope
- prepare a deletion request
- identify derived data affected by a source deletion
- explain why deletion is blocked by policy

Quanty cannot:
- bypass retention policy
- release a compliance hold
- erase data directly
- expand export scope
- declare deletion complete without lifecycle verification

Memory candidates remain subject to shared memory policy and source-data lifecycle rules.
