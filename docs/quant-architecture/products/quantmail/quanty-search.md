# QuantMail Quanty — Search

## Read-only assistance

Quanty may help transform natural language into an explicit search plan.

Examples:
- "Find the invoice from last week"
- "Show unread messages from the school"
- "Find the presentation I shared with X"

Quanty returns:
- interpreted intent
- selected domains
- structured filters
- optional clarification request

The actual search executes through normal product/search APIs.

## Security

Natural-language interpretation cannot bypass:
- authorization
- privacy scope
- tenant boundaries
- retention policies

Quanty does not receive all indexed documents merely to plan a query.
