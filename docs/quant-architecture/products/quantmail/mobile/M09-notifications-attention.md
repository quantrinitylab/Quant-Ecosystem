# QuantMail Flutter — M09 Attention

## Mobile

Attention center is a full-screen workflow.

Components:
- top app switcher
- priority groups
- attention cards
- source chip
- action area
- bottom contextual navigation

## Gestures

Allowed:
- swipe to mark read
- swipe to dismiss only for dismissible categories

Not allowed:
- swipe-to-send
- swipe-to-delete security records
- swipe-to-approve high-risk actions

## Offline

Read/unread intent may queue locally.
Resolution of consequential items requires server confirmation.
