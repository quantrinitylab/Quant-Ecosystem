# QuantMail Flutter — M10 Settings

## Navigation

Searchable grouped list:
- Account
- Mail
- Notifications
- Quanty
- Privacy & Security
- Devices
- Appearance

Detail pages use native platform controls where appropriate.

## Safety

Security-sensitive actions use dedicated confirmation screens.
Never place revoke-all or account deletion beside ordinary toggles without separation.

## Offline

Read-only settings may use cached values.
Security and identity mutations require online confirmation.
