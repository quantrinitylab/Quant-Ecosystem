# M11 — Quanty and Mail Admin

Quanty may assist administrators with:
- explaining policy configuration
- finding affected mailboxes
- summarizing audit activity
- drafting a policy change
- generating impact previews

Quanty cannot:
- grant itself admin capability
- change organization roles
- silently alter retention/security policy
- execute broad mutations without the required admin approval
- bypass audit requirements

For consequential admin changes:
Quanty prepares; admin policy decides; authorized administrator approves; domain executes; system verifies.
