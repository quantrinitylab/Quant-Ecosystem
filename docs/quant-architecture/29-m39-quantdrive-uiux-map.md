# M39 — QuantDrive UI/UX Journey Map

## File retrieval
Home → My Drive → folder → preview → related context → return.

## Upload
New/Upload → system picker → upload queue → scan → available → preview/share.

## Organization
Select files → move/copy or Quanty suggestion → destination picker → confirm → verified location.

## Sharing
File → Share → current access → proposed audience/permission → save → verified access.

## Version recovery
File → Versions → inspect timeline → restore chosen version → verify current state.

## Mail attachment
Mail → attachment → Drive preview/save → canonical Drive file → return to Mail.

## Search
Universal search → Files scope → filters → result → preview → return with search context.

## Completion criterion
Design and frontend teams can implement core Drive workflows without inventing ownership, security, upload, sharing, preview, or recovery semantics.
