# @quant/admin-enterprise — Enterprise Organization Admin Console

Dedicated enterprise multi-tenant administration platform for corporate organizations on the Quant Ecosystem.

## Core Pillars

1. **Domains & DNS Hub (`/domains`)**: Visual 5-step DNS verification wizard (TXT token, MX routing, SPF, 2048-bit DKIM CNAMEs, DMARC, BIMI SVG & VMC certificates).
2. **Directory & Identity (`/directory`)**: Multi-level Organizational Units (OUs), SCIM 2.0 provisioning for Okta/Azure AD, and SAML 2.0 SSO enforcement.
3. **Compliance & Mail Routing (`/compliance`)**: DLP regex rules, mandatory corporate disclaimer footers, and quarantine review escrow.
4. **Security & Investigation (`/security`)**: Real-time cross-service event audit log explorer, SIEM webhook export, and 1-click employee account lock.
5. **Device Management & MDM (`/devices`)**: Device enrollment inventory, security posture compliance, and remote corporate wipe.
6. **eDiscovery & Legal Hold (`/ediscovery`)**: Google Vault equivalent for custodian litigation holds and court-admissible MBOX/PST export with SHA-256 manifests.
