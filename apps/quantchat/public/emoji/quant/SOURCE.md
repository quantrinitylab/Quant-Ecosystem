# Quant Originals — asset source note (QC-F-336, Slice 1)

These 12 WebP files are first-party originals made for QuantChat in this
build (2026-10-15). Each one was drawn programmatically from simple
geometric primitives (circles, polygons, arcs, a parametric heart curve)
with Python Pillow — emerald/gold brand palette — at a 512px supersample
and downscaled to 128×128. Animated entries are multi-frame animated WebP
(140ms/frame, looping).

No emoji font (Noto/Twemoji or any other), no Telegram/WhatsApp/Snapchat
pack, no stock site art was copied, traced, recoloured or hotlinked.
Reproduction script: `hidden_files/loop/build-qc-f-336-make-assets.py`
in the QuantChat supremacy goal workspace (loop build lane records).
